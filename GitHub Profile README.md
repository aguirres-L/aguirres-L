# Hi, I'm Agustin 👋

**Product-focused Developer · React / React Native**

I'm a developer based in Córdoba, Argentina, mainly working with **React, React Native and TypeScript**.

What interests me most about software is not only how to build something, but **why it needs to be built in the first place**.

I like understanding how a business works, where a process gets stuck and what can be improved through software. I usually ask a lot of questions before starting because the people working inside a business understand their problems better than anyone.

Before becoming a developer, I spent several years working in operations and logistics. That experience shaped the way I approach software today: **understand the workflow, find the bottleneck and then look for the simplest useful solution.**

## How I approach development

I try to avoid adding complexity without a reason.

My approach is usually to build the **simplest bridge that proves an idea works**, validate it and improve it from there.

I care about good architecture, reusable components and clear separation of responsibilities, but I don't believe that using the newest technology automatically makes a product better.

Sometimes the best solution is simply the one that works well and solves a real problem.
